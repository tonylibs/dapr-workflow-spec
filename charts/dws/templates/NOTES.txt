{{- if .Values.apiGateway.enabled }}
The shared API Gateway is enabled. Console and admin share one Gateway API front door
(GatewayClass {{ include "dws.apiGateway.className" . }}, Gateway {{ include "dws.apiGateway.gatewayName" . }}):
  - `/dws-admin/*` routes through Dapr service invocation to the dws-admin sidecar's
    bearer-gated middleware (dws-admin's app port is not directly reachable).
  - every other path routes to dws-console.

{{- else }}
APISIX/Gateway API is externally managed (apisix.enabled=false); this chart only renders the
GatewayClass/Gateway/HTTPRoute objects, bound to apiGateway.external.gatewayProxyName.

Dex (dws-console's in-chart IdP) is enabled.

{{- if .Values.dex.adminUser.existingSecret }}

  kubectl get secret {{ include "dws.dex.adminCredentials.fullname" . }} -n {{ include "dws.namespace" . }} -o jsonpath='{.data.email}' | base64 -d; echo
  kubectl get secret {{ include "dws.dex.adminCredentials.fullname" . }} -n {{ include "dws.namespace" . }} -o jsonpath='{.data.password}' | base64 -d; echo
